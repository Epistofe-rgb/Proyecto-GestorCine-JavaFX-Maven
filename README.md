#Proyecto JavaFX con Maven

APlicacion desarrollada en IntelliJ IDEA usando JaaFX y Scene Builder

##Requisitos
- JDK 26
- JavaFX SDK 26
- Maven

##Como ejecutar
1. Clonar el repositorio.
2. Abrir en IntelliJ IDEA
3. Ejecutar con VM Options:
    --module-path "ruta/javafx-sdk-26/lib" --add-modules javafx.controls,javafx.fxml
